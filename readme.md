Excitebike NES ROM Text Editor v.1.0.0.29971 (including source)<br/>
Programmed by: Shawn M. Crawford [sleepy] 03/26/2016 in C#<br/>
---------------------------------------------------------<br/>

Features:<br/>
	* edit text in the game <br/>
	* works with the USA/Japan ROM<br/>

Usage:<br/>
	*Open the Rom, change text, click update, make sure you have a backup in case something breaks.<br/>
	*This is first release so it will probably have bugs, feel free to email bugs to sleepy3d@gmail.com<br/>
